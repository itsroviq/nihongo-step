# 🌸 Nihongo Step

### Zero to JLPT N5

Nihongo Step is a Japanese learning application designed for learners starting from zero.

The learning journey introduces Japanese fundamentals and gradually builds the skills needed for JLPT N5.

## ✨ Features

- Beginner-friendly Japanese learning
- Japanese writing practice
- Reading practice
- Grammar lessons
- Vocabulary development
- Structured learning progression
- JLPT N5-oriented materials

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the main HTML file in a modern browser.
3. Begin with the introductory lessons.

## 🛠️ Technology

- HTML5
- CSS3
- JavaScript
